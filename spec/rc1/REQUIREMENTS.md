# Requirements

MUST and MUST NOT are mandatory. Each row names the owning subsystem, the source entries it inherits from (A = Source A section, B = Source B requirement, M = master prompt section, R = reconciliation entry) and the artifacts and tests that verify it. `tools/gen_traceability.py` generates TRACEABILITY.csv from these tables; `tests/contract/test_traceability.py` checks that every referenced path exists and that every requirement is traced. Numeric targets are proposals (see ASSUMPTIONS_AND_DECISIONS.md) until measured.

Categories: PR product, SR system, IC integration contract, DC data contract, SI security invariant, AT acceptance test.
